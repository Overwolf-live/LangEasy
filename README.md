# LangEasy — вивчай японську як гру

Gamified PWA для вивчення японської (JLPT N5–N3). Інтерфейс українською.

## Що всередині
- **Кана** — хірагана й катакана (основні, дзвінкі, сполучення): вибір, введення ромадзі, малювання.
- **Канджі** — 517 ієрогліфів N5–N3: значення, онʼомі/кунʼомі, читання слів, малювання.
- **Слова** — ~1380 слів за темами (N5–N3): переклад, читання, пари.
- **Ситуації** — складання речень + **візуальні новели** (26 історій з персонажами, фонами й діалогами з вибором).
- **RPG-персонаж** — клас, зовнішність, рівень героя (XP), спорядження за рівнями, серія днів, монети.
- **Профіль** — шкала до наступного рівня героя та шкала «рівня знань» (за кількістю вивчених елементів).
- **Повторення** слабких місць (Leitner-подібна система «коробок»).
- Збереження в браузері (localStorage), експорт/імпорт у профілі. Працює офлайн (service worker).

## Запуск
```
npm install
npm run dev       # розробка
npm run build     # продакшн-збірка в dist/
npm run validate  # перевірка JSON-контенту
```

## Контент
Дані лежать у `src/data/raw/*.json` (схеми — `docs/CONTENT_SCHEMA.md`). Вправи (варіанти, дистрактори, порядок) генеруються процедурно під час уроку.
Контент згенеровано AI і не проходив перевірку носієм мови — можливі неточності.
